# Energy Advisor

Aplicação web para análise de faturas de energia elétrica e apoio à tomada de decisão energética.

## Tecnologias

- HTML5
- CSS3
- Vue.js 3
- Chart.js
- Supabase
- PostgreSQL
- Git/GitHub

## Funcionalidades

- Página inicial responsiva
- Login simplificado
- Controle de acesso aos serviços
- Simulador energético
- Recomendações automáticas
- Histórico de análises
- Integração preparada com banco de dados PostgreSQL via Supabase

## Como configurar o banco de dados

1. Crie uma conta em https://supabase.com
2. Crie um projeto chamado `energy-advisor`
3. Acesse `SQL Editor`
4. Execute o arquivo `database.sql`
5. Acesse `Project Settings > API`
6. Copie `Project URL` e `anon public key`
7. Cole esses dados no início do arquivo `script.js`
